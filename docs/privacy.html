プライバシーポリシー

取得する情報と目的

本人の同意を得て、Gmailの読み取り専用権限（gmail.readonly）を使用します。権限はメールボックス全体の読み取りを許可しますが、利用目的は本人の家計管理に必要な利用通知の確認です。メールの送信・変更・削除は行いません。

接続先のメールアドレス、メールのID・送信元・件名を確認し、対象のメールのヘッダと本文から利用日時・金額・利用先などを読み取ります。

保存と共有

現在は読み取りの試運転です。取得したメールと利用情報は実行中のみ処理し、アプリに保存しません。継続アクセスに必要な認証情報は、本人の端末に暗号化して保存します。

取得したメールやメール由来のデータを外部サービスへ送信せず、第三者への提供・販売、広告、AIによる解析や学習には使用しません。Google APIとの通信は行います。

Googleから取得した情報の利用は、制限付き使用（Limited Use）の要件を含むGoogle API Services User Data Policyに従います。

アクセスの停止と削除

Googleアカウントの接続管理からアクセス許可を取り消せます。利用終了時はアプリを停止し、保存した認証情報とそのバックアップを本人が削除してください。Gmail上の元メールは残り、必要に応じて本人がGmailで削除します。

このサイトとお問い合わせ

この説明サイトでは家計データを受け付けず、独自のCookie・アクセス解析・広告は使用しません。配信元によるアクセス情報の取り扱いはGitHubのプライバシーステートメントをご確認ください。

データの取り扱いを変更する際は、事前に本ポリシーを更新し、必要に応じて本人の同意を得ます。
